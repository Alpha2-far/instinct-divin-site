# INSTINCT DIVIN — Site Web Officiel

Site web vitrine, catalogue artisanal et portail de formation pour la pâtisserie-boulangerie **INSTINCT DIVIN** à Cotonou, Bénin.

## 🍰 Présentation

- **Activité :** Pâtisserie artisanale fine, gâteaux d'événements (mariage, anniversaire, communion), viennoiseries pur beurre, traiteur cocktail & formations professionnelles.
- **Localisation :** Cotonou, Bénin
- **Contact & WhatsApp :** +229 66 48 75 65
- **Réseaux :** [Facebook](https://www.facebook.com/Instinctdivinchezsylvan) | [Instagram](https://www.instagram.com/instinct_divin1) | [Google Maps](https://maps.app.goo.gl/5irE1LpfZJMFtZVR9)

## 📁 Structure du site

- `index.html` : Page d'accueil, présentation, catalogue avec prix, avis et FAQ
- `formation.html` : Programme des formations professionnelles en pâtisserie et boulangerie
- `conditions-commandes.html` : Modalités de commande, délais, acomptes et livraisons
- `mentions-legales.html` : Mentions légales et conformité
- `politique-confidentialite.html` : Politique de confidentialité APDP Bénin
- `404.html` : Page d'erreur personnalisée
- `sitemap.xml` & `robots.txt` : Référencement naturel & SEO local
- `vercel.json` : Configuration de sécurité (headers HTTP, cache assets)
- `assets/` : Feuilles de style CSS, scripts JS et photographies des créations

## 🚀 Déploiement

Le site est optimisé pour être hébergé sur [Vercel](https://vercel.com).
